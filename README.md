# E-Commerce Sales Analytics Dashboard

An end-to-end E-Commerce Sales Analytics project built using **Python, SQL, SQLite, and Excel**.

The project focuses on cleaning and transforming raw sales data, performing SQL-based business analysis, and creating an interactive Excel dashboard to understand sales performance.

---

## 📌 Project Overview

This project analyzes an e-commerce sales dataset containing order, product, quantity, price, date, and customer location information.

The analysis covers:

- Data cleaning and preprocessing
- Feature creation using Python
- Sales and revenue calculations
- SQL-based business analysis
- SQLite database integration
- Excel-based reporting and dashboard creation
